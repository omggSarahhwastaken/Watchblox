# Watchblox

**Know when your friends play.**

Watchblox is a Roblox friend & presence companion for Windows. Enter your
Roblox username once, and it keeps a live dashboard of your friends: who's
offline, online, in game, or in Studio — what game each person is in, an
activity feed of every coming and going, Windows notifications, and a **Join**
button that drops you straight into an in-game friend's exact server. No
browser. No extension.

No login needed. No admin needed. Watchblox only reads public data.

## Download

Grab the latest installer from the
[Releases page](https://github.com/omggSarahhwastaken/Watchblox/releases).
The app updates itself when new versions are out.

## Features

- **Live presence dashboard** — status, game names, avatars, search & filters
- **Activity feed** — every online/offline/game change, as it happens
- **Windows toast notifications** — know the moment a friend hops in game
- **Join button** — one click into your friend's exact server
- **Watchlist** — track anyone by username, even non-friends
- **Self-updating** — installs updates automatically

## Privacy

- No Roblox login or cookie required — everything is public data.
- No telemetry, no accounts, nothing phones home except update checks
  and Roblox's own public API.
- All data (settings, activity history, cached avatars) stays in
  `%LocalAppData%/Watchblox/` on your PC.

## Requirements

- Windows 10 or 11 (64-bit)
- Roblox Player installed (for the Join button)
- Internet connection, obviously
